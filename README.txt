MAK2B Professional App — Client + Admin prototype
========================================================
هذه نسخة جديدة مبنية على التصور المعتمد:
- Splash وخلفية MAK2B المعتمدة.
- Cairo Bold/ExtraBold.
- 8 أقسام رئيسية.
- رحلة العميل كاملة من الاختيار حتى إرسال الطلب ومراجعته.
- صفحة الشركات مع البريد: adil.maktob01@gmail.com وInstagram: Maak22b.
- تعهد صحة المعلومات والالتزام.
- خانة خدمتي مع حالات السعر والتأكيد/الرفض.
- زر إدارة صغير أعلى اليمين.
- تسجيل دخول الإدارة لأول مرة ينشئ كلمة مرور محلية (للنموذج التجريبي فقط).
- لوحة إدارة: الطلبات الجديدة، قيد الإنجاز، المنجزة، المرفوضة، الأسعار، الطباعة/PDF، الزيارات والتثبيتات.

مهم للإنتاج:
هذه نسخة PWA/واجهة أولية احترافية. ربط الطلبات بين أجهزة الزبائن والإدارة، المصادقة الحقيقية، الخرائط، الإشعارات، الإحصائيات المركزية، وعدّ تثبيتات التطبيق الحقيقي تحتاج Backend وقاعدة بيانات وخدمة مصادقة/إشعارات.
زر "طباعة / PDF" يستخدم نافذة الطباعة في الجهاز، ويمكن اختيار "Save as PDF".
